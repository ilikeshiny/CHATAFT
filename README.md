# CHATAFT - Comprehensive Hosted Autonomous Transmitting Architecture For ...Toasting?

TL;DR: A multi-modular, mult-platform bridging bot for shitposters &amp; niche communities alike!  

# About the project: 

This have been a project of mine for the past year; but since the great (upcoming) fall of Discord due to Palantir association, i've been seeing a lot of the new platforms pop up from thin air, confusing people as to where to go instead of actually helping them migrate. It started as a simple, two-way Telegram <--> Discord bridge i've made because all other opensource projects sucked - could not even download from Discord's CDN properly.
So after the massive revamp i've done in February 2026, this project aims to be a migration tool for a large variety of communities - niche chatrooms, art channels and shitposts. 

All battle tested in the [REDAFT](https://the_redaft/) community

> [!TIP]
> The features:
> - catch-up of missed messages during bot's downtime or component crash;
> - full chat exports from discord (telegram wip);
> - intelligent message ordering by time: perfect chat history preservation;
> - smart discord cdn embed pulling: automatic detection of raw media vs rich embeds;
> - large variety of supported media types: stickers, emojis, system messages;
> - seamless discord &amp; stoat integration: full webhook and masquerade support with avatar pulling and webhook reply bypassing (referencing the message link instead of legacy reply) 
> - fully functional rich dashboard with real-time updates;
> - support for discord's threads and telegram's topics;
> - 4 way bridging, thanks to RabbitMQ's mailing queues
> - and more!

> [!WARNING]
> Cons:
> - tedious setup: have to install and configure Erlang and RabbitMQ;
> - fully generated by LLMs (not an issue for most people - especially when considering the human intent behind the project)

> [!NOTE]
> What's planned:
> - full Matrix AS mode support;
> - privacy settings for users who wish to not disclose their nickname or content to other platforms;
> - web panel config;
> - (X)Twitter write-only support (API is costly there);
> - Bluesky two-way support;
> - Possibly Slack and Mattermost, but not sure if that's my scope
> - Telegram webhooks and clientbot support for export functionality and delete detection
> - Discord read-only clientbot support for dead communities that need archiving

> [!WARNING]
> What's NOT planned:
> - Teamspeak - this platform is centered around voice channels, not text. Matrix has largely superseded TeamSpeak imo;
> - Any russian government-backed platforms and like their western platform copycats
